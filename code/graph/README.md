# Case Representation Learning (CRL)

This directory contains the multi-level graph representation learning implementation used by DSLaw's **Case Representation Learning (CRL)** module.

CRL uses case representations, charge representations, semantic IDs, and codebook vectors exported by the **Hierarchical Semantics Encoding (HSE)** module to construct graphs over case, charge, and code-ID nodes.

Start the training process by executing the corresponding dataset's `run.sh` in `train/`.
