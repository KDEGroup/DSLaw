#### LLM summary
The case concerns defendants who developed and provided game cheat programs that were judicially determined to be destructive software. Forensic evaluations found that the programs “LWImsx” and “88888.exe” conducted unauthorized operations on the games CrossFire and PUBG, including adding or modifying running programs, interfering with normal system processes, uploading user data without authorization, capturing user interfaces, and remotely controlling users’ computers. These functionalities constituted destructive programs and demonstrated that the software was specially used for intrusion into or illegal control of computer information systems. The court determined that at least one defendant was aware of the nature and effects of the cheats, including the need to disable antivirus software, establishing subjective criminal intent. Based on the objective conduct and subjective intent, the court held that the defendants’ actions satisfied the elements of the crime of providing programs or tools for intrusion into or illegal control of computer information systems. In its final judgment, the court found all defendants guilty, distinguishing between serious and particularly serious circumstances among them, and imposed corresponding criminal liability accordingly.

### HSE module
Given the semantic representation generated from the LSE module, the embedding vector is progressively decomposed across multiple quantization layers. At each layer:

1. The current residual representation is matched to the nearest prototype vector in a learned codebook.
2. The index of the selected prototype is recorded as the code ID for that layer.
3. The selected prototype is subtracted from the representation, producing a residual that is passed to the next layer.

Formally, for an input representation $\mathbf{z}$, the process iteratively performs nearest-neighbor assignment over layer-wise codebooks, generating a sequence of discrete indices $\text{ID}^{(1)}, \text{ID}^{(2)}, \ldots, \text{ID}^{(L)}$

Importantly, these IDs are not manually annotated labels. They are learned through contrastive training over positive and negative case pairs, and their semantic tendencies are identified via post-hoc corpus-level analysis rather than predefined textual attributes.

After multi-layer residual quantization in HSE, the case is assigned the semantic ID sequence [26, 17, 58, 41, 17, 3].

### CRL module
#### The structure of the graph
At a single layer, CRL constructs a graph that connects each case to two key elements: its annotated charge and its assigned semantic ID from HSE. For the example case, this means linking the case node to its legal charge (capturing explicit legal structure) and to its discrete code ID (capturing latent semantic similarity learned through residual quantization). Other cases that share the same ID are indirectly connected through this ID node, forming a small semantic neighborhood. In addition, similar charges and similar ID nodes are connected based on embedding similarity, ensuring the graph reflects broader conceptual relationships.

For instance, this case is connected to its charge node (cybercrime-related offense) at every layer. Specifically, it connects to ID node #26 in the first layer and ID node #3 in the last layer. Furthermore, 83% of the cases connected to ID node #26 in the first layer are related to cybercrime; in contrast, while ID node #3 in the last layer is associated with only 27% of cybercrime cases, more than 61% of those cases involve multiple perpetrators and severe circumstances.

#### Representation Fusion and Retrieval

After graph reasoning at each layer, we obtain a case representation from every semantic level. The final representation of a case is constructed by concatenating all layer-wise graph outputs together with the original PCA-whitened embedding. This produces a unified vector that simultaneously contains coarse domain information, mid-level structural patterns, and fine-grained judicial nuances. During retrieval, similarity is computed using cosine similarity over the fused representations.

This fusion strategy ensures that retrieval is not dominated by a single semantic level. Shallow layers help match cases within the same legal domain, while deeper layers help distinguish subtle factual or sentencing differences. By combining all layers, the model balances broad legal relevance with fine-grained discrimination, leading to more stable and accurate case retrieval.
